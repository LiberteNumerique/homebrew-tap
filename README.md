# LiberteNumerique Tap

## How do I install these formulae?

`brew install libertenumerique/tap/<formula>`

Or `brew tap libertenumerique/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "libertenumerique/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
